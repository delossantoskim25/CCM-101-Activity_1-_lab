
# AWS Platform Research

## Brief Overview
Amazon Web Services (AWS) launched publicly in 2006 and is the global market leader in cloud computing. As a subsidiary of Amazon, AWS provides on-demand cloud computing platforms and APIs to individuals, companies, and governments on a metered pay-as-you-go basis.

## Global Infrastructure
* **Regions:** 33+ Geographic Regions worldwide.
* **Availability Zones (AZs):** 105+ Availability Zones, each featuring isolated power, cooling, and physical security.
* **Edge Network:** 600+ Points of Presence (PoP) across CloudFront CDN locations.

## Cloud Management Console
The AWS Management Console provides a web-based portal to access and manage all AWS services. Users can navigate resources via searching, organized dashboards, custom widgets, or through programmatic interfaces such as the AWS CLI and Software Development Kits (SDKs).

![AWS Management Console](assets/aws-console.png)

## Four Core Services
1. **Amazon EC2 (Elastic Compute Cloud):** Resizable virtual virtual machines in the cloud.
2. **Amazon S3 (Simple Storage Service):** Highly scalable object storage designed for data backup, analytics, and archiving.
3. **Amazon VPC (Virtual Private Cloud):** Logically isolated virtual networks for running resources securely.
4. **AWS IAM (Identity and Access Management):** Access control system for securely managing permissions to AWS services and resources.

## Three Advantages
* **Market Maturity & Breadth:** Widest array of features and services with deep enterprise-grade maturity.
* **Global Footprint:** Massive ecosystem of data centers ensuring low latency and high reliability globally.
* **Extensive Ecosystem:** Huge marketplace of third-party integration tools, active user communities, and documentation.

## Typical Enterprise Use Cases
* **Enterprise Application Migration:** Rehosting legacy internal workloads to cloud infrastructure.
* **Global E-Commerce Hosting:** Deploying auto-scaling web architectures that handle fluctuating web traffic.
* **Big Data Analytics & Lakes:** Storing unstructured raw data in S3 and processing it with tools like Amazon EMR or AWS Glue.
