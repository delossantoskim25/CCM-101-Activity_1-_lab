## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of cloud services, boasting over 200 fully featured services spanning compute, databases, IoT, machine learning, and serverless architectures. Its early head start in the cloud industry enabled it to build the most comprehensive ecosystem available today.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best integration with Microsoft technologies because it natively supports legacy Windows architectures, Active Directory environments, and SQL Server databases. Enterprises can effortlessly extend on-premises Windows setups into Azure using native identity management via Microsoft Entra ID and take advantage of cost savings through Azure Hybrid Benefit.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest provider in Artificial Intelligence and Kubernetes because Google originally created Kubernetes and built GCP around containerized architectures. Furthermore, GCP leads in AI/ML through advanced proprietary infrastructure like Tensor Processing Units (TPUs) and state-of-the-art developer suites like Vertex AI.

### 4. Which cloud platform would you personally choose and why?
I would personally choose Amazon Web Services (AWS) because of its unmatched documentation, immense market share, and global community support. Mastering AWS provides flexible solutions across nearly any domain while providing strong alignment with industry demand for cloud engineers.
