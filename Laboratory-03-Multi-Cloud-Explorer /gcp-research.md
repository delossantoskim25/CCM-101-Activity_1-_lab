
# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP), launched in 2008, is a suite of cloud computing services that runs on the same infrastructure that Google uses internally for its end-user products, such as Google Search, Gmail, and YouTube.

## Global Infrastructure
* **Regions:** 40+ Regions worldwide.
* **Availability Zones:** 120+ Zones across all global regions.
* **Edge Network:** Directly connected to Google's massive global fiber-optic backbone for low latency network transport.

## Cloud Management Console
The Google Cloud Console provides an intuitive web interface to manage GCP resources. It features built-in Cloud Shell capabilities, project-centric grouping, resource monitoring metrics, and streamlined access to Google's data analysis tools.

![GCP Console](assets/gcp-console.png)

## Four Core Services
1. **Google Compute Engine (GCE):** High-performance virtual machine instances running on Google's infrastructure.
2. **Google Cloud Storage (GCS):** Unified, durable object storage for developers and enterprise customers.
3. **Google Cloud VPC:** Global virtual private cloud network connecting resources across all zones without public internet routing.
4. **Google Cloud IAM:** Fine-grained access control and visibility for managing Google Cloud resources.

## Three Advantages
* **Data & AI Leadership:** Unmatched capabilities in Big Data processing, Machine Learning tools, and AI hardware (TPUs).
* **Kubernetes Expertise:** Native container management excellence; Google originally created Kubernetes.
* **Global Private Network:** High-speed, low-latency network infrastructure running across Google's backbone.

## Typical Enterprise Use Cases
* **Artificial Intelligence & ML Workloads:** Training complex machine learning models using Vertex AI and TensorFlow.
* **Real-time Big Data Analytics:** Processing streaming telemetry data using BigQuery and Cloud Dataflow.
* **Containerized Microservices:** Running microservices architectures managed by Google Kubernetes Engine (GKE).
