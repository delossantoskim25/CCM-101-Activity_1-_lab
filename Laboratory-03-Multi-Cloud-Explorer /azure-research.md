
# Microsoft Azure Platform Research

## Brief Overview
Microsoft Azure, launched in 2010 (originally as Windows Azure), is Microsoft's public cloud computing platform. Azure integrates directly with Microsoft's enterprise ecosystem, making it the top choice for companies deeply invested in Windows technologies and hybrid enterprise solutions.

## Global Infrastructure
* **Regions:** 60+ Regions available worldwide (more geographic regions than any other provider).
* **Availability Zones:** Designed with independent power, network, and cooling within every primary region.
* **Edge Network:** Hundreds of edge locations integrated into Microsoft's private global fiber network.

## Cloud Management Console
The Azure Portal is a unified, web-based console that provides an alternative to command-line tools. With the Azure Portal, you can manage your Azure subscription using a graphical user interface to build, manage, and monitor everything from simple web apps to complex cloud deployments.

![Azure Portal](assets/azure-portal.png)

## Four Core Services
1. **Azure Virtual Machines:** On-demand, scalable computing resources running Linux or Windows Server.
2. **Azure Blob Storage:** Massively scalable object storage for unstructured data such as text, images, or binary data.
3. **Azure Virtual Network (VNet):** Private network isolation block within Azure for internal resource networking.
4. **Microsoft Entra ID (formerly Azure Active Directory):** Cloud-based identity and access management service.

## Three Advantages
* **Seamless Microsoft Integration:** Native alignment with Windows Server, Active Directory, SQL Server, and Microsoft 365.
* **Hybrid Cloud Dominance:** Industry-leading hybrid cloud capabilities with Azure Arc and Azure Stack.
* **Enterprise Licensing Discounts:** Hybrid Benefit savings for existing Windows Server and SQL Server licenses.

## Typical Enterprise Use Cases
* **Hybrid Enterprise Deployments:** Synchronizing on-premises Active Directory with cloud apps via Entra ID.
* **Windows Workload Modernization:** Hosting enterprise Active Directory, SharePoint, and .NET applications.
* **Disaster Recovery:** Using Azure Site Recovery for enterprise business continuity strategies.
