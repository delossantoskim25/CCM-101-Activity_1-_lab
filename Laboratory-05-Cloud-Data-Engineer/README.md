
# Laboratory 05 - The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed an S3-compatible object storage
server using MinIO and Docker. I created a storage bucket and uploaded a
sample file to demonstrate how object storage can be used for cloud
applications.

## Objectives

- Understand the differences between Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through port forwarding.
- Create an object storage bucket.
- Upload an object to the bucket.
- Document the deployment using Markdown.
